# 🎬 Carpeta de Videos para Pruebas Locales

## Uso

Coloca videos de prueba aquí (archivos `.mp4`, `.webm`):

```
public/
  videos/
    curso-ejemplo-1.mp4
    curso-ejemplo-2.mp4
```

## En el Admin Panel

Cuando crees un curso, usa estas URLs:

```
http://127.0.0.1:5000/public/videos/curso-ejemplo-1.mp4
```

## Alternativa: Videos de muestra online

Puedes usar videos de prueba públicos:

- **Big Buck Bunny:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4`
